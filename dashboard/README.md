# SheSecure Authority Dashboard

Discreet, information-dense emergency command center built with React 18, Vite, TypeScript, and Tailwind CSS.

## Features
- **Real-Time Telemetry**: Live polling of active distress alerts.
- **Interactive Mapping**: Leaflet emergency map with incident markers and accuracy radii.
- **Incident Lifecycle Management**: Status transitions (`ACTIVE` -> `ACKNOWLEDGED` -> `RESPONDING` -> `RESOLVED` / `DISMISSED`).
- **Audit Trail Inspector**: Complete chronological event ledger.
- **Demo Mode Simulator**: Safe test alert injector for presentations.

## Local Setup
```bash
npm install
npm run dev
```
Access at `http://localhost:5173`.
